PROJET – GESTION DE BIBLIOTHÈQUE MUNICIPALE

Règles métier – User Stories – Structure BDD – Exemple complet avec Avis & Favoris

DOCUMENT 1 – RÔLES & RÈGLES MÉTIER

1️⃣ Lecteur (ex : Yanis)
Après connexion :
  • Accès au catalogue complet : recherche par titre, auteur, catégorie, filtre par disponibilité.
  • Voir l'état de chaque livre :
    • 📗 Disponible → peut emprunter
    • 📕 Emprunté → peut réserver
    • 🔒 Réservé → bloqué pour un autre lecteur
  • Accès à ses emprunts en cours avec dates de retour.
  • Accès à son historique d'emprunts et réservations.
Actions possibles :
  • Emprunter un livre disponible
    Exemple : Livre A disponible → Yanis clique "Emprunter" → livre emprunté 21 jours → date de retour automatique.
  • Réserver un livre déjà emprunté
    Exemple : Livre B emprunté par Lucas → Yanis réserve → réservation activée → livre bloqué 7 jours dès son retour → si Yanis ne vient pas → réservation annulée.
  • Laisser un avis (note + commentaire)
  • Ajouter un livre en favori
⚠️ CONTRAINTES IMPORTANTES :
  • Maximum 5 emprunts simultanés
  • Durée de prêt : 21 jours
  • Prolongation possible : 1 fois, 7 jours supplémentaires (si pas de réservation en attente)
  • Maximum 3 réservations actives
  • Blocage du compte si retard > 14 jours
2️⃣ Bibliothécaire (ex : Sarah)
Après connexion :
  • Accès au catalogue complet, tous les livres.
  • Accès à la liste de tous les lecteurs et leurs emprunts/réservations.
  • Accès aux emprunts en cours et retards.
Actions possibles :
  • Créer un emprunt pour un lecteur physique
    Exemple : Lucas vient au comptoir pour Livre C → Sarah choisit Lucas et Livre C → emprunt enregistré 21 jours.
  • Enregistrer un retour
    Exemple : Lucas rend Livre C → système met à jour : disponible ou réservé pour un autre lecteur (7 jours).
  • Gérer le catalogue : ajouter, modifier, supprimer un livre.
  • Gérer les lecteurs : créer, modifier ou bloquer un compte.
  • Supprimer des avis inappropriés.
3️⃣ Responsable municipal (ex : Mme Dupont)
Accès au tableau de bord :
  • Nombre d'inscrits
  • Nombre de livres empruntés
  • Top livres
  • Retards

Ne peut pas emprunter ni modifier le catalogue.

DOCUMENT 2 – USER STORIES

📖 Lecteur (Yanis)

  • Consulter le catalogue et voir l'état des livres.
  • Chercher un livre par titre, auteur ou catégorie.
  • Emprunter un livre disponible → date retour 21 jours.
  • Réserver un livre déjà emprunté → bloqué 7 jours après retour.
  • Consulter mes emprunts et réservations en cours et l'historique.
  • Laisser un avis (note + commentaire).
  • Ajouter un livre en favori.
  • Prolonger un emprunt (si éligible) : ajouter 7 jours si le livre n'est pas réservé par quelqu'un d'autre ET si pas déjà prolongé avant.

👩‍💼 Bibliothécaire (Sarah)

  • Créer un emprunt pour un lecteur → choisir le lecteur et le livre.
  • Enregistrer un retour → mettre à jour le statut du livre.
  • Gérer le catalogue (ajout, suppression, modification).
  • Gérer les lecteurs (création, modification, blocage).
  • Supprimer des avis inappropriés.
  • Consulter les retards et envoyer des rappels.

👨‍💼 Responsable (Mme Dupont)

  • Consulter les statistiques : nombre d'inscrits, livres empruntés, réservations, retards.
  • Exporter les données (CSV, PDF).

Types de notifications automatiques :

  • Rappel retour (J-3) : 3 jours AVANT la date de retour → "N'oubliez pas de rendre le livre"
  • Retard J+1 : 1 jour APRÈS la date de retour → "Votre livre est en retard"
  • Retard J+7 : 7 jours APRÈS → "Retard urgent" + blocage des nouveaux emprunts
  • Retard J+14 : 14 jours APRÈS → Compte suspendu automatiquement
  • Réservation disponible : Quand un livre réservé est prêt à retirer (7 jours pour venir)
  • Compte suspendu : Quand le compte est bloqué suite à un retard important

RELATIONS SIMPLES

  • Lecteur → Emprunts : un lecteur peut emprunter plusieurs livres (max 5).
  • Livre → Emprunts : un livre peut être emprunté plusieurs fois (selon quantité disponible).
  • Lecteur → Réservations : un lecteur peut réserver plusieurs livres (max 3).
  • Livre → Réservations : un livre peut être réservé par plusieurs lecteurs dans l'ordre (file d'attente).
  • Lecteur → Avis : peut laisser plusieurs avis (1 seul par livre).
  • Lecteur → Favoris : peut ajouter plusieurs favoris.
  • Bibliothécaire → Emprunts/Retours : gère tous les emprunts et retours pour les lecteurs physiques.
  • Responsable → Statistiques : consulte les données, ne modifie rien.

EXEMPLES CONCRETS

1️⃣ Livre B emprunté par Lucas

➡ Yanis réserve Livre B → réservation activée (position 1)
➡ Lucas rend Livre B → livre bloqué 7 jours pour Yanis
➡ Yanis vient dans les 7 jours → emprunt activé (21 jours)
➡ Yanis laisse un avis ⭐⭐⭐⭐⭐ et ajoute le livre en favori
➡ Si Yanis ne vient pas → réservation annulée après 7 jours, livre disponible pour tous

2️⃣ Livre A disponible (2 exemplaires)

➡ Yanis emprunte directement → date retour 21 jours
➡ Quantité disponible passe de 2 à 1
➡ Livre reste disponible pour d'autres lecteurs
➡ Yanis peut laisser un avis et mettre en favori
➡ Yanis peut prolonger de 7 jours (si pas de réservation)

3️⃣ Livre C réservé (bloqué 7 jours pour Emma)

➡ Aucun autre lecteur ne peut réserver ni emprunter
➡ Emma doit venir avant le 13/12/25
➡ Si Emma ne vient pas → réservation expire → livre disponible

  • J+1 : Email "Livre en retard"
