📝 Cahier des charges - BiblioConnect

📌 1. Cadre du projet

📄 1.1. Résumé

BiblioConnect est une application web communautaire destinée aux lecteurs francophones souhaitant accéder facilement au catalogue d'une bibliothèque municipale, emprunter des livres, effectuer des réservations et découvrir de nouvelles lectures adaptées à leurs goûts.

L'application permet aux utilisateurs de créer un compte lecteur, de consulter le catalogue de 100 000 livres, de rechercher des ouvrages selon plusieurs critères (titre, auteur, genre, disponibilité), de réserver des livres, de laisser des avis et d'échanger via un système de recommandations personnalisées.

L'objectif principal de BiblioConnect est de faciliter l'accès à la culture, d'améliorer l'expérience de lecture et de lutter contre les difficultés à trouver le bon livre. L'application vise également à optimiser le travail du personnel de la bibliothèque en automatisant les tâches répétitives comme les rappels de retour ou la gestion des réservations.

🌍 1.2. Contexte du projet

Avec la montée en puissance du numérique et des services en ligne, de nombreux lecteurs souhaitent pouvoir consulter le catalogue de leur bibliothèque depuis chez eux, vérifier la disponibilité d'un livre avant de se déplacer, et recevoir des notifications pour leurs emprunts.

Les solutions existantes sont souvent complexes (logiciels professionnels type Koha, PMB) ou dispersées (sites web peu ergonomiques, pas d'application mobile).

BiblioConnect s'inscrit dans une volonté de moderniser l'accès à la bibliothèque au sein d'une application web moderne, intuitive et pensée spécifiquement pour les lecteurs de tous âges et de tous niveaux techniques.

🎯 1.3. Enjeux et objectifs

  • ✅ Faciliter la recherche de livres dans un catalogue de 100 000 ouvrages
  • ✅ Centraliser les informations des lecteurs et leurs emprunts
  • ✅ Permettre la réservation de livres non disponibles
  • ✅ Automatiser les notifications (rappels de retour, livres disponibles)
  • ✅ Offrir un système d'avis et de recommandations personnalisées
  • ✅ Favoriser l'engagement des lecteurs avec des favoris et un historique
  • ✅ Proposer une expérience web fluide et moderne (responsive mobile/desktop)
  • ✅ Poser des bases solides pour des évolutions futures (application mobile native, etc.)

📦 1.4. Livrables

  • 📌 Une application web fonctionnelle (SPA React + API Laravel)
  • 📌 Une interface utilisateur claire, moderne et ergonomique
  • 📌 Un système d'authentification et de gestion de profil lecteur
  • 📌 Une base de données de 100 000 livres (OpenLibrary)
  • 📌 Un système de recherche avancée optimisé (Big Data)
  • 📌 Un système de réservations avec file d'attente
  • 📌 Un système de favoris et d'avis
  • 📌 Un module de gestion des emprunts/retours (bibliothécaires)
  • 📌 Un dashboard administrateur avec statistiques
  • 📌 Un système de notifications automatiques par email
  • 📌 Une API REST sécurisée et documentée

📊 2. Benchmark

🔎 2.1. Présentation des plateformes analysées

📚 2.1.1. Koha

Koha est un système intégré de gestion de bibliothèque (SIGB) open-source, utilisé par de nombreuses bibliothèques dans le monde.

Avantages :

  • Solution complète et professionnelle
  • Open-source et gratuit
  • Fonctionnalités très riches (catalogage, prêts, acquisitions)

Faiblesses :

  • Interface utilisateur datée et peu intuitive
  • Complexité d'installation et de configuration
  • Peu adapté aux petites bibliothèques ou aux utilisateurs non-techniques

📕 2.1.2. Babelio

Babelio est un réseau social français dédié aux livres et aux lecteurs, permettant de découvrir des livres, lire des critiques et échanger avec d'autres lecteurs.

Avantages :

  • Interface moderne et agréable
  • Communauté francophone très active
  • Système d'avis et de recommandations performant
  • Catalogue de livres très complet

Faiblesses :

  • Pas de gestion de prêts ou de réservations
  • Pas conçu pour les bibliothèques (usage personnel uniquement)
  • Pas de fonctionnalités pour le personnel

📗 2.1.3. BnF Catalogue

Le catalogue en ligne de la Bibliothèque nationale de France permet de rechercher parmi des millions de documents.

Avantages :

  • Catalogue très complet et fiable
  • Recherche avancée puissante
  • Données bibliographiques de référence

Faiblesses :

  • Interface austère et peu engageante
  • Expérience utilisateur complexe pour les non-initiés
  • Pas de fonctionnalités communautaires

💡 2.2. Enseignements pour BiblioConnect

BiblioConnect doit se différencier par :

  • Une UX simple et directe
  • Une recherche de livres optimisée pour gérer 100 000 ouvrages
  • Une approche communautaire (avis, recommandations) inspirée de Babelio
  • Un focus sur les lecteurs francophones de tous âges
  • Une application pensée responsive-first (mobile et desktop)

⚙️ 6. Spécifications Techniques

🖥 6.1. Architecture Générale

BiblioConnect repose sur une architecture moderne et évolutive, combinant SPA, API REST et responsive-first pour une expérience fluide et performante.

📌 Structure en trois couches :

  • Application Web (Frontend) 🖥 : Utilisation de React avec Vite, permettant une expérience SPA fluide sur tous les appareils.
  • Backend (API) 🏗 : API construite avec Laravel 10 + Sanctum (authentification JWT).
  • Base de données 🗄 : PostgreSQL, optimisée pour le Big Data (100 000 livres) avec index et recherche full-text.
  • Cache 🚀 : Redis pour accélérer les requêtes fréquentes.

🛠 6.2. Technologies Utilisées

Domaine Technologie
Frontend 🖥 React 19 + Vite + Tailwind CSS
Backend 🏗 Laravel 10 + Sanctum (JWT)
Base de données 🗄 PostgreSQL (optimisé Big Data)
Cache 🚀 Redis
Hébergement ☁️ Vercel (frontend) + Railway (backend + BDD)
Authentification 🔐 Laravel Sanctum (JWT)
API Livres 📚 OpenLibrary (import initial)
Emails 📧 Laravel Mail + SMTP

🔐 6.3. Sécurité & RGPD

  • Chiffrement des mots de passe (bcrypt)
  • Authentification sécurisée JWT
  • Protection CSRF et CORS
  • Validation stricte des données (FormRequests Laravel)
  • Conformité RGPD (suppression de compte, export des données)
  • HTTPS obligatoire en production
